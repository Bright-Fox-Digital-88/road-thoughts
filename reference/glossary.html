Transformers & Attention · Reference

Glossary

The canonical language for this course. Lessons adhere to these terms.

A term lands here only once it's genuinely understood — this is a record of compressed knowledge, not a dictionary to read cold.

Attention

Query (Q)
A token's learned projection meaning "what I'm looking for." It scores against every key to decide where to attend. Avoid: search term, question vector.

Key (K)
A token's learned projection meaning "what I offer, so others can find me." Compared against queries via dot product. Avoid: index, address.

Value (V)
A token's learned projection holding the content actually handed over when attended to. The attention output is a weighted sum of values. Avoid: payload, data.

Attention score
The raw dot product of one query with one key — a single number for "how relevant is this token to me," before scaling or softmax. Avoid: similarity, match.

Scaled dot-product attention
The core operation softmax(Q·Kᵀ / √dk)·V: score, scale, softmax, blend. The heart of the transformer. Avoid: the attention formula.

Softmax (in attention)
The step that turns scaled scores into positive weights summing to one — a probability distribution over which tokens to attend to. Avoid: normalization.

Attention weights
The post-softmax distribution itself: how much each token listens to each other token. This is where "what the model is attending to" literally lives. Avoid: attention scores (those are pre-softmax).

The blend
Workspace shorthand for the final weighted sum of value vectors — attention always returns a mix, never a single winner. Story: the Cup.

Structure & flow

Layer
One full round of mix then digest: attention across tokens, then a per-token feed-forward step. Models stack dozens (GPT-3 has 96). Each layer re-contextualizes the last. Story: a movement of the evening, called by the Bell.

Feed-forward step
The per-token "digest" inside a layer: each token processes its own blend alone, with no awareness of other tokens. The most parallel part of the machine. Story: the Study.

Causal mask
The rule that a token may attend only to tokens before it, never after. Makes each token's state depend only on its left context — which is what makes caching exact. Story: the Threshold Rule. Avoid: look-ahead block.

KV cache
The stored keys and values for one specific running sequence, computed once and reused so each new generated token isn't recomputed from scratch. Valid because of the causal mask.

Prefill vs decode
Prefill: pushing the whole prompt through all layers in parallel (the expensive, quadratic part). Decode: generating one token at a time, reusing the KV cache.

Still to be added as you master them: multi-head attention, temperature, positional encoding, residual stream.
