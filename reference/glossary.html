Transformers & Attention · Reference

Glossary

The canonical language for this course. Lessons adhere to these terms.

A term lands here only once it's genuinely understood — this is a record of compressed knowledge, not a dictionary to read cold.

Attention

Query (Q)
A token's learned projection meaning "what I'm looking for." It scores against every key to decide where to attend. Avoid: search term, question vector.

Key (K)
A token's learned projection meaning "what I offer, so others can find me." Compared against queries via dot product. Avoid: index, address.

Value (V)
A token's learned projection holding the content actually handed over when attended to. The attention output is a weighted sum of values. Avoid: payload, data.

Attention score
The raw dot product of one query with one key — a single number for "how relevant is this token to me," before scaling or softmax. Avoid: similarity, match.

Scaled dot-product attention
The core operation softmax(Q·Kᵀ / √dk)·V: score, scale, softmax, blend. The heart of the transformer. Avoid: the attention formula.

Softmax (in attention)
The step that turns scaled scores into positive weights summing to one — a probability distribution over which tokens to attend to. Avoid: normalization.

Attention weights
The post-softmax distribution itself: how much each token listens to each other token. This is where "what the model is attending to" literally lives. Avoid: attention scores (those are pre-softmax).

The blend
Workspace shorthand for the final weighted sum of value vectors — attention always returns a mix, never a single winner. Story: the Cup.

Structure & flow

Layer
One full round of mix then digest: attention across tokens, then a per-token feed-forward step. Models stack dozens (GPT-3 has 96). Each layer re-contextualizes the last. Story: a movement of the evening, called by the Bell.

Feed-forward step
The per-token "digest" inside a layer: each token processes its own blend alone, with no awareness of other tokens. The most parallel part of the machine. Story: the Study.

Causal mask
The rule that a token may attend only to tokens before it, never after. Makes each token's state depend only on its left context — which is what makes caching exact. Story: the Threshold Rule. Avoid: look-ahead block.

KV cache
The stored keys and values for one specific running sequence, computed once and reused so each new generated token isn't recomputed from scratch. Valid because of the causal mask.

Prefill vs decode
Prefill: pushing the whole prompt through all layers in parallel (the expensive, quadratic part). Decode: generating one token at a time, reusing the KV cache.

State & representation

Residual stream
The single fixed-length vector that is a token at any moment — the only persistent state. Every layer adds into it; nothing overwrites it. Serves as both a store of accumulated meaning and a shared scratchpad. Story: the Ledger of You. Avoid: the token's state, the hidden vector (use these loosely, but prefer "residual stream").

Residual connection
The rule that each block's output is added to its input rather than replacing it (x + update). What makes identity continuous and the original token a fading echo. Story: the Rule of the Ledger.

Erasure (additive)
Suppressing information by adding a vector that cancels an existing one — possible because numbers can be negative. A trained reflex, not a runtime decision. Story: the Cancelling Line.

Communication channel / workspace
The view of the residual stream as a message bus: each component reads from and writes to particular directions, leaving notes later components pick up (composition). Story: the Margin Notes.

Superposition
The packing of many features into overlapping directions of the same vector, so structure is real and linear but not axis-aligned (no "dimension 7 = noun"). Why the workspace is hard to read.

Read-out (token to token)

Unembedding
The final projection that turns the summit vector into one score per vocabulary token, by dot product against a table of fixed token signatures. Often the input embedding table, transposed (weight tying). Story: the Dictionary of Signatures + the Door Read Backwards.

Logits
The raw, un-normalised scores — one per vocabulary token — produced by the unembedding, before softmax. Story: the Weighing.

Summit
Workspace shorthand for the final position's vector, which (via attention up the layers) already holds a distillation of the whole context window. The only vector read out at generation time.

Temperature
A scaling of the logits before softmax that sets boldness: low → sharp/near-deterministic, high → flat/varied. Story: the Boldness Dial. Avoid: randomness, creativity (it tunes them, it isn't them).

Sampling
Drawing the next token from the softmax distribution. Greedy = take the top one; top-k / top-p = restrict to the most probable candidates first.

Autoregressive loop
Generate one token, append it, run the pass again (reusing the KV cache) to generate the next. Story: the Door Read Backwards.

Chain-of-thought (CoT)
Emitting intermediate reasoning as tokens before the final answer. Works because each emitted token gets its own full forward pass and becomes a durable, re-attendable record — extending the model's finite per-step compute and memory. Mechanically no different from any other token; the distinction is content/convention. Story: the Pinned Note.

Multi-head attention

Attention head
One of several parallel attentions in a layer, each with its own Q/K/V in a slice of the width (d_model / H). Each forms its own attention distribution over the same tokens. Story: a steward.

Multi-head attention
Splitting attention into H heads that run in parallel, then concatenating their outputs and applying a learned output projection to merge them. Lets the model track several kinds of relationship at once, nearly for free (the width is partitioned). Story: the Council + the Chamberlain.

Induction head
A head (working with a previous-token head) that finds an earlier occurrence of the current pattern and copies what followed it — the discovered mechanism behind in-context learning. Why few-shot prompting and format-following work. Story: the Two Stewards Who Learn On The Fly.

In-context learning
The model adapting to patterns in the prompt (examples, formats) without any weight change, largely via induction heads. Avoid: the model "learning" from your prompt (no training occurs).

Applied (context & chat)

Chat template / role tokens
Special marker tokens (system / user / assistant) plus fine-tuning that teach a uniform mechanism to treat text by role. The user/assistant distinction is convention, not different machinery. Story: One Uniform, Many Costumes.

Attention dilution
Because each token's attention sums to one, more competing tokens give each a thinner average share — a key reason long contexts degrade. Story: the Finite Heart.

Lost in the middle
The empirical bias by which models attend well to the start and end of a long context and neglect the middle. Story: Lost in the Middle.

Meaning & grounding

Distributional hypothesis
The principle that a word's meaning is captured by the company it keeps — its pattern of co-occurrence with other words. The basis on which an LLM learns meaning purely from relation. Firth: "you shall know a word by the company it keeps."

Meaning-transducer
Workspace framing for the whole model: language (compressed meaning) in → decompress tokens to meaning-coordinates → re-compose into a situated meaning-point → read back to language out.

Symbol grounding problem
The open question of whether symbols manipulated relationally (as in an LLM) carry meaning in the human sense, given they are not grounded in sensory/embodied reference. Where human and AI cognition are hardest to compare.

Training

Pretraining
The bulk phase: self-supervised next-token prediction over a giant corpus, where the meaning-space and knowledge are built. Story: the ten thousand evenings.

Loss (cross-entropy)
A measure of "surprise" — how little probability the model placed on the token that actually came next. Training minimises it. Story: the Measure of Surprise.

Backpropagation
Computing, for every weight, how much it contributed to the loss and which way to change it — the credit/blame assignment run backward through the network. Story: the Accountant.

Gradient descent
Nudging every weight a small step (the learning rate) in the direction that reduces the loss. Tiny steps by design. Story: the Nudge.

Emergence
The appearance of meaning, grammar, and knowledge as byproducts of getting good at prediction — never a stated objective. Story: Structure Precipitates.

Fine-tuning / RLHF
Smaller post-training phases (instruction-tuning, preference-tuning) that shape behaviour and manners, not core knowledge. Story: Finishing School.

Frozen weights
After training, all weights are locked; the model does not learn from your prompts. In-context adaptation is induction heads reading the context, not the weights changing. Story: the Frozen Host.
