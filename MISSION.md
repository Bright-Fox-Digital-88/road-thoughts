# Mission: How the Human Brain Handles Attention, Meaning, and Memory

## Why
The user has spent significant time learning how LLMs work internally — attention,
context, memory, and the philosophical gap between tokens and meaning. They now want
to complete the picture by understanding the *human* side of that same equation, so
they can reason clearly and precisely about human–AI collaboration: what a person's
brain is actually doing when it attends, understands, and hands work off to a model
and then picks it back up.

## Success looks like
- Can explain human attention as a capacity-limited selection mechanism, and say
  precisely where the LLM "attention" parallel holds and where it breaks.
- Can describe, mechanically, how meaning/concepts are represented in the brain
  (distributed features + an integrating hub), not just hand-wave "semantics."
- Can account for the "spin-up / hand-off / spin-back-up" experience in neural terms:
  why a warmed-up problem representation fades to background and must be reconstituted.
- Uses correct nomenclature (dorsal/ventral attention, biased competition, hub-and-spoke,
  working-memory maintenance, goal reactivation) without prompting.

## Constraints
- Knowledge-heavy topic: ground every claim in trusted sources, never parametric guesses.
- Learner is conceptually sophisticated (strong mental model of LLM internals already) —
  pitch to that, use the LLM parallel as scaffolding, but flag it honestly when the
  analogy is misleading.
- Short lessons, one win each, within working-memory limits.

## Out of scope (for now)
- Clinical neuroscience / neuroanatomy for its own sake (lesion localization, pathways).
- Molecular/cellular detail (receptors, LTP biochemistry) beyond what a concept needs.
- Consciousness as a metaphysical problem — we stay mechanistic.
