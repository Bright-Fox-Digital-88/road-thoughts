# Resources

High-trust resources for grounding lessons on transformers & attention. Primary
sources (papers, canonical explainers, interactive tools) are preferred over blog
restatements.

## Primary / canonical
- **Attention Is All You Need** (Vaswani et al., 2017) — the original paper.
  https://arxiv.org/abs/1706.03762
  *The source of truth. Section 3.2 (Scaled Dot-Product & Multi-Head Attention).*
- **The Illustrated Transformer** — Jay Alammar.
  https://jalammar.github.io/illustrated-transformer/
  *The canonical visual walkthrough of Q/K/V and the attention computation. Best
  first read for building intuition.*

## Interactive (great for skill practice)
- **Transformer Explainer** — Polo Club, Georgia Tech.
  https://poloclub.github.io/transformer-explainer/
  *Live, in-browser GPT-2 you can poke. Watch attention weights and the softmax
  change as you type. Excellent for tying theory to a running model.*

## Supporting explainers
- **Query, Key, Value: The Foundation of Transformer Attention** — M. Brenndoerfer.
  https://mbrenndoerfer.com/writing/query-key-value-attention-mechanism
- **"Attention, Please!" — A Visual Guide to the Attention Mechanism.**
  https://codecompass00.substack.com/p/visual-guide-attention-mechanism-transformers

## Communities (for wisdom / testing understanding)
- r/MachineLearning and r/LocalLLaMA (Reddit) — practitioner discussion.
- Eleuther AI / Hugging Face forums — for deeper mechanistic questions.
